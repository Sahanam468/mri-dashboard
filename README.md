# 🧠 AI MRI Brain Tumor Diagnostic System

This project performs:
- MRI tumor **classification** (InceptionV3)
- **Tumor segmentation** (U-Net)
- **Tumor coverage measurement**
- **LLM-based radiology report generation** (Google Gemini)
- **Apollo-style PDF creation**
- **Interactive AI assistant chatbot**

### Technologies Used
- Streamlit
- TensorFlow / Keras
- Google Gemini API
- OpenCV
- ReportLab

### How to Run
pip install -r requirements.txt
streamlit run app.py


### Warning
This is a **research/academic tool**, not a clinical diagnosis system.
